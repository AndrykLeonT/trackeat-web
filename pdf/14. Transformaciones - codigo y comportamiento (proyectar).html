rotate() + transform-origin girar, y desde dónde

El pivote no cambia cuánto gira. Cambia qué gesto es.

.cubo {
  transform-origin: 50% 50%;
  transform: rotate(45deg);
}

/* Por omisión el pivote es el centro.
   El punto rojo lo marca. */
gira

Qué pasa El mismo rotate(45deg) produce tres movimientos que se sienten completamente distintos. Lo único que cambió fue dónde está el punto rojo.

skew() inclinar

Deforma la caja empujando un eje. El menos usado de los cuatro.

.cubo {
  transform: skewX(20deg);
}
skew

Qué pasa El texto de adentro se inclina con la caja: la transformación se aplica al elemento completo y a todo su contenido.

El orden de las funciones no se suman: se encadenan

Las mismas dos funciones, invertidas, dan resultados distintos.

/* Mueve, y luego gira sobre sí misma */
.a {
  transform: translateX(60px) rotate(45deg);
}

/* Gira el sistema de coordenadas, y
   luego mueve sobre el eje ya inclinado */
.b {
  transform: rotate(45deg) translateX(60px);
}

transform-style: preserve-3d mantener a los hijos en 3D

Sin esto, los hijos se aplanan contra el plano del padre.

.escena { perspective: 800px; }

.tarjeta {
  transform-style: preserve-3d;
  transform: rotateY(180deg);
}

.cara.atras {
  transform: rotateY(180deg);
}

Qué pasa Con flat, la cara de atrás deja de existir en el espacio 3D y ya no aparece al girar, aunque el código de esa cara no se tocó.

backface-visibility la cara de atrás es un espejo

Si no la ocultas, ves el reverso del propio elemento, invertido.

.cara {
  backface-visibility: hidden;
}

Qué pasa Con visible, al girar se ve el texto del frente reflejado. Es el mismo elemento visto por detrás, como una hoja de papel a contraluz.

translate · rotate · scale como propiedades sueltas

Con transform, la segunda regla pisa a la primera. Con las propiedades sueltas, no.

/* PIERDE el scale al pasar el puntero */
.caja {       transform: scale(1.4); }
.caja:hover { transform: rotate(15deg); }

/* CONSERVA las dos */
.caja {       scale: 1.4; }
.caja:hover { rotate: 15deg; }

pásame el puntero

Qué pasa El de la izquierda pierde el tamaño al girar, porque la regla de :hover reemplaza la declaración completa. El de la derecha conserva las dos cosas.
